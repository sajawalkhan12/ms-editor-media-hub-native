# Mobile se aglay steps

1. ZIP ko phone par download aur extract karein.
2. GitHub par `ms-editor-media-hub-native` repository kholen.
3. `Add file` > `Upload files` dabayein.
4. Extract kiye gaye project ke andar ki files/folders upload karein (ZIP file ko seedha repository mein upload karne se project build nahi hota).
5. `Commit changes` dabane se pehle check karein ke `app`, `gradle` agar maujood ho, `settings.gradle.kts`, `build.gradle.kts` aur `README.md` repository ke root par hon.
6. APK banane ke liye Android build runner/Android Studio environment chahiye. Is ZIP mein abhi GitHub Actions build workflow shamil nahi hai; aglay step mein usay add kiya ja sakta hai.

Har step ke baad screenshot bhejein. Agla step screenshot dekh kar bataya jayega.
